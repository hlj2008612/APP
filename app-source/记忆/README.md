# 项目记忆索引

> 这是本项目（photo-wall-vue / 美琴的照片墙）的长期记忆目录。
> **每次对话开始时必须先读本文件，再按需读其余文件。**

## 使用约定

1. 新对话开场：先读 `README.md` + `01-项目概览.md`，再读与本次任务相关的专题文件。
2. 每次完成任务后：把新的重要结论追加到对应文件（尤其是 `04-缺陷与修复.md` 和 `07-对话历史.md`）。
3. 记忆只记录**已核实**的事实。推断和猜测必须明确标注「推断」。
4. 用户明确要求「每次都要调用专家」—— 遇到需要审查/验收的任务，优先用 Agency 专家，而不是自己一个人硬扛。

## 文件清单

| 文件 | 内容 |
|---|---|
| `01-项目概览.md` | 项目定位、技术栈、目录结构、路由、当前版本状态 |
| `02-架构与设计决策.md` | 各模块职责、关键算法、为什么这么设计 |
| `03-构建与部署.md` | 构建产物、部署流程（worktree 方式）、线上核对方法 |
| `04-缺陷与修复.md` | 已修复的全部缺陷清单（含根因与验证数据） |
| `05-环境与工具.md` | 无头浏览器、截图、GitHub API 等环境事实与坑 |
| `06-用户偏好与协作约定.md` | 用户的语言、风格、工作方式偏好 |
| `07-对话历史.md` | 按轮次记录的对话要点与用户决策 |
